# DataFrame Reporter

Небольшой учебный проект на Python.

## Что делает проект

Программа загружает данные из файла `payments.csv` и с помощью класса `DataFrameReporter` выводит простой отчёт о данных.

В отчёте показывается:

* количество строк и столбцов;
* количество дубликатов;
* доля дубликатов;
* статистика по данным;
* количество пропусков;
* доля пропусков.

## Как установить

Сначала нужно создать виртуальное окружение:

```bash
python -m venv venv
```

Для Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

После этого установить зависимости:

```bash
pip install -r requirements.txt
```

## Как запустить

Запуск программы:

```bash
python main.py
```

После запуска отчёт выводится в консоль.

Файл с данными должен находиться здесь:

```text
data/payments.csv
```
